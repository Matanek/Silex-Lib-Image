# Image for Silex

`Image` loads, saves, and transforms raster images through one
intention-oriented API with built-in PNG, JPEG, and WebP support.

```text
silex install Image
```

## Documentation

- [French documentation](Docs/FR/README.md)
- [English documentation](Docs/EN/README.md)

The package requires Silex 0.48.0 or newer.
